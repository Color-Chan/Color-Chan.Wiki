An overview of all the available Whitelist commands.

## /color blacklist add
Adds a role to the color blacklist.

## /color blacklist overview
Returns an overview of the color blacklist.

## /color blacklist remove
Removes a role from the color blacklist.

## /color whitelist add
Adds a role to the color whitelist.

## /color whitelist overview
Returns an overview of the color whitelist.

## /color whitelist remove
Removes a role from the color whitelist.
