An overview of all the available Miscellaneous commands.

## /bot info
Returns information about the current version of Color-Chan.

## /donate
Returns information about donating to Color-Chan on Patreon.

## /help
Shows a list of commands and what the commands do.

## /invite
Returns the invite link for Color-Chan.

## /patreon connect
Connects a server with your Patreon account.

## /patreon disconnect
Disconnects a server from your Patreon account.

## /patreon info
Returns some info about your Patreon subscription.

## /premium
Returns information about the premium features of Color-Chan.

## /support
Returns the invite where you can ask for support with Color-Chan.

## /vote
Returns the link where you can vote for Color-Chan.
