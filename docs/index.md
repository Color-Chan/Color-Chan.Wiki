# Color-Chan Wiki

Welcome to the documentation for Color-Chan's documentation. Everything you need to get started with Color-Chan is available here!

## About Color-Chan

Color-Chan is a Discord bot that allows server to create a custom color palette using simple commands to create a fun and colorful Discord server.
